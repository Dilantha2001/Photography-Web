## ✨ Features

* 🖼️ **Immersive Galleries:** Optimized image grids to display high-resolution photography.
* 📱 **Flawless Responsiveness:** Pixel-perfect design across mobile, tablet, and desktop viewing.
* 🖋️ **Elegant Typography:** Utilizing `Noto Serif Display` for a sophisticated, editorial feel.
* 📖 **Integrated Journal:** A dedicated space for storytelling and blogging.
* ✉️ **Client Inquiries:** Built-in contact architecture for booking and networking.

## 🛠️ Tech Stack

## 🗺️ Site Architecture

Navigating the application is handled seamlessly via React Router:

| Route | Component | Description |
| :--- | :--- | :--- |
| `/` | `<Home />` | The stunning landing page and hero section. |
| `/portfolio` | `<PortfolioPage />` | Curated showcase of best works. |
| `/galleries` | `<Containertwo />` | Categorized photo collections. |
| `/journal` | `<Journal />` | Blog and photography narratives. |
| `/experience`| `<ExpereancePage />`| Professional background and milestones. |
| `/about` | `<Containerfirst />` | Artist biography and vision. |
| `/contact` | `<ContactForm />` | Inquiry and booking interface. |
